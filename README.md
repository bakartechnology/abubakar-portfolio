## ⚙️ Getting Started

### 1. Installation
Clone the repository and install dependencies:
```bash
npm install
```

### 2. Environment Variables (Optional)
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```
Add your keys if you want to forward contact inquiries through an email provider:
```env
NEXT_PUBLIC_SITE_URL=https://abubakar-portfolio.vercel.app
RESEND_API_KEY=re_your_api_key_here
EMAIL_FROM=onboarding@resend.dev
EMAIL_TO=bakartechnology@gmail.com
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 4. Build for Production
To test and create an optimized production build:
```bash
npm run build
```

### 5. Start Production Server
```bash
npm run start
```

## 🚀 Deploying to Vercel

1. Push your repository to GitHub (`github.com/bakartechnology/portfolio`).
2. Log in to [Vercel](https://vercel.com/) and click **Add New Project**.
3. Import this repository.
4. Framework preset will automatically be detected as **Next.js**.
5. Add any environment variables (e.g. `RESEND_API_KEY`).
6. Click **Deploy**.
